# Product Guidelines

## Design Principles
- **Speed & Lightness First:** Keep the executable compact (< 2-3 MB), portable, with zero runtime installs beyond standard .NET / Windows runtime.
- **Pixel-Perfect Sharpness:** Ensure UI icons and control borders render sharp at integer device pixels (`SnapsToDevicePixels="True"`, `UseLayoutRounding="True"`).
- **Calm, Focused Aesthetic:** Use neutral slate/zinc dark surfaces (`#18181B`, `#27272A`) and soft light surfaces without harsh oversaturated primary colors.
- **Native OS Harmony:** Behave like a first-class Windows 11 application with working Snap Layouts, window snapping, standard shortcuts, and fluid DPI scaling.
