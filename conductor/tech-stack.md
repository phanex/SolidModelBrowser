# Technology Stack

## Core Technologies
- **Runtime & Framework:** .NET Framework 4.8 / WPF (Windows Presentation Foundation)
- **Language:** C# 8.0+
- **Rendering Engine:** Direct3D 9 / WPF `Viewport3D` with hardware acceleration
- **SketchUp Library:** `OpenSkp` (.NET managed package from NuGet)
- **CI/CD Platform:** GitHub Actions (`windows-latest` / Visual Studio 2022 / MSBuild)
- **Asset Formats:** Vector SVG and Pixel-Perfect PNGs
